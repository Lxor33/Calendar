后端启动与关闭说明

一、启动后端

1. 打开 PowerShell 或 VS Code 终端。

2. 进入后端文件夹：

cd C:\D\AAjavascript\backend

3. 启动后端：

npm start

4. 如果看到下面这行，说明后端启动成功：

Schedule backend is running at http://127.0.0.1:3000

5. 启动成功后，不要关闭这个终端窗口。保持它运行，再打开前端页面。


二、验证后端是否正常运行

在浏览器打开：

http://127.0.0.1:3000/api/health

如果看到类似下面的内容，说明后端和数据库连接正常：

{"success":true,"message":"OK"}


三、打开前端

请使用 VS Code 的 Live Server 打开 login.html，不要直接双击 HTML 文件。

推荐地址：

http://127.0.0.1:5500/login.html

注意：前端和后端要同时运行。


四、关闭后端

在运行 npm start 的终端窗口中按：

Ctrl + C

如果终端询问是否终止批处理作业，输入：

Y

然后按回车。

关闭后，再访问：

http://127.0.0.1:3000/api/health

如果显示无法连接，说明后端已经关闭。


五、常见问题

1. 如果前端提示“网络错误，请确认后端已启动”，说明后端没有运行。请重新执行：

cd C:\D\AAjavascript\backend
npm start

2. 如果后端启动时报数据库连接错误，请检查 backend\.env 里的数据库密码是否正确。

3. 如果登录状态异常，前端地址尽量使用 127.0.0.1，不要一会儿用 localhost，一会儿用 127.0.0.1。
